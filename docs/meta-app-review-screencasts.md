# Сценарии скринкастов для Meta App Review

Каждый скринкаст демонстрирует конкретное permission и его использование в приложении.
Рекомендуемая длительность: 30-60 секунд каждый.

---

## Threads Permissions

### 1. threads_basic — Чтение профиля и постов

**Что показать:** приложение читает профиль и посты подключённого аккаунта.

1. Открыть miniapp → **Настройки** → **Социальные сети**
2. Нажать **"Подключить Threads"** — показать OAuth-экран (consent screen)
3. После авторизации → показать что аккаунт подключён (зелёная галочка, username)
4. Перейти в **Тренды** → вкладка **Threads**
5. Показать список постов аккаунта с метриками (лайки, реплаи)
6. Нажать на пост → показать детальный просмотр (текст, статистика, ссылка на оригинал)

**API-вызовы:** `GET /me` (профиль), `GET /{user_id}/threads` (посты)

---

### 2. threads_content_publish — Публикация контента

**Что показать:** приложение публикует ответ на упоминание в Threads.

1. Открыть **Упоминания** (Контент → Упоминания)
2. Выбрать входящее упоминание с платформой "Threads"
3. Нажать **"Сгенерировать ответы"** → показать 3 варианта с разным тоном
4. Выбрать один вариант → нажать **"Опубликовать"**
5. Показать статус "Опубликовано" с зелёной галочкой
6. Открыть Threads в браузере — показать что ответ появился

**API-вызовы:** `POST /{user_id}/threads` (создать контейнер), `POST /{user_id}/threads_publish`

---

### 3. threads_manage_replies — Управление ответами

**Что показать:** приложение читает и публикует ответы в тредах.

1. Открыть **Упоминания** → выбрать упоминание типа "comment"
2. Показать контекст поста и цепочку ответов
3. Сгенерировать AI-ответ → опубликовать
4. Показать что ответ опубликован в правильном треде

**API-вызовы:** `GET /{thread_id}/replies`, `POST /{user_id}/threads` (reply)

---

### 4. threads_manage_insights — Аналитика

**Что показать:** приложение отображает метрики вовлечённости.

1. Открыть **Тренды** → вкладка **Threads**
2. Показать **карточки постов** с метриками: лайки, репосты, просмотры, ответы
3. Показать **"Лучшее время публикации"** — график по часам
4. Показать **"Лидеры репостов"** — посты с наибольшим количеством репостов
5. Показать **"Сравнение"** (вкладка Сравнение) — Threads vs Instagram

**API-вызовы:** `GET /{post_id}/insights` (views, likes, replies, reposts, quotes)

---

### 5. threads_read_replies — Чтение ответов

**Что показать:** приложение читает входящие ответы на посты.

1. Открыть **Упоминания** → фильтр по платформе **Threads**
2. Показать список входящих упоминаний (ответы на посты)
3. Открыть конкретное упоминание → показать полный контекст
4. Показать автора, текст ответа, timestamp, ссылку на оригинал

**API-вызовы:** `GET /{thread_id}/replies`, `GET /{thread_id}/conversation`

---

### 6. threads_manage_mentions — Управление упоминаниями

**Что показать:** приложение мониторит и обрабатывает упоминания бренда.

1. Открыть **Упоминания** → фильтр **Threads** → статус **pending**
2. Показать новые упоминания бренда (входящие)
3. Выбрать упоминание → показать детали
4. Сгенерировать AI-ответ → показать варианты
5. Нажать **"Игнорировать"** для нерелевантного упоминания → показать изменение статуса
6. Опубликовать ответ на релевантное упоминание

**API-вызовы:** `GET /me/mentions`

## Instagram Permissions

### 7. instagram_business_basic — Базовый доступ

**Что показать:** приложение читает профиль и медиа бизнес-аккаунта.

1. Открыть **Настройки** → **Социальные сети** → **"Подключить Instagram"**
2. Показать OAuth consent screen
3. После авторизации → показать подключённый аккаунт
4. Перейти в **Тренды** → вкладка **Instagram**
5. Показать посты с метриками (лайки, комментарии)
6. Показать **хэштег-облако** — визуализация популярных тегов
7. Показать **тепловую карту** активности (дни × часы)

**API-вызовы:** `GET /me`, `GET /{user_id}/media`, `GET /ig_hashtag_search`

---

### 8. instagram_business_content_publish — Публикация контента

**Что показать:** приложение создаёт и публикует пост в Instagram.

1. Открыть **Создать** → выбрать формат (фото или карусель)
2. Написать текст поста или сгенерировать AI-контент
3. Выбрать изображение
4. Нажать **"Опубликовать в Instagram"**
5. Показать прогресс (создание контейнера → проверка статуса → публикация)
6. Показать успешно опубликованный пост

**API-вызовы:** `POST /{user_id}/media`, `POST /{user_id}/media_publish`

---

### 9. instagram_business_manage_comments — Управление комментариями

**Что показать:** приложение читает комментарии и отвечает на них.

1. Открыть **Упоминания** → фильтр по платформе **Instagram**
2. Показать входящие комментарии к постам
3. Выбрать комментарий → показать контекст (оригинальный пост + комментарий)
4. Сгенерировать AI-ответ → выбрать вариант
5. Нажать **"Опубликовать"** → ответ публикуется как комментарий
6. Открыть Instagram → показать ответ под постом

**API-вызовы:** `GET /{post_id}/comments`, `POST /{media_id}/comments`

---

### 10. instagram_business_manage_insights — Аналитика

**Что показать:** приложение собирает и отображает аналитику постов.

1. Открыть **Тренды** → вкладка **Instagram**
2. Показать **топ-посты** с метриками вовлечённости
3. Показать **форматы контента** — распределение (фото/видео/карусель)
4. Показать **тепловую карту** — активность по дням и часам
5. Перейти в **Сравнение** → показать Instagram vs Threads
6. Нажать на пост → показать детальные метрики (лайки, комментарии, просмотры)

**API-вызовы:** `GET /{post_id}/insights` (impressions, reach), `GET /{post_id}?fields=like_count,comments_count`

---

### 11. instagram_business_manage_messages — Сообщения

**Что показать:** приложение мониторит входящие сообщения (DM).

1. Открыть **Упоминания** → фильтр **Instagram** → тип **dm**
2. Показать входящие DM (если есть)
3. Показать содержание сообщения, автора, timestamp
4. Сгенерировать AI-ответ или перейти к DM в Instagram

**API-вызовы:** Webhook-based — Instagram отправляет уведомления о новых DM

## Подготовка к записи

### Перед записью:
1. Убедиться что все OAuth-токены свежие (Настройки → Соц. сети)
2. Добавить 2-3 аккаунта для мониторинга (Настройки → Аккаунты на мониторинг)
3. Добавить 3-5 хештегов (Настройки → Теги для мониторинга)
4. Нажать **"Обновить"** в Трендах — дождаться сбора данных
5. Убедиться что есть хотя бы 1-2 упоминания в разделе Упоминания

### Порядок записи (рекомендуемый):
1. **threads_basic** + OAuth flow (подключение)
2. **threads_manage_mentions** (входящие упоминания)
3. **threads_read_replies** (чтение ответов)
4. **threads_manage_replies** (публикация ответа)
5. **threads_content_publish** (публикация поста)
6. **threads_manage_insights** (аналитика Threads)
7. **instagram_business_basic** + OAuth flow
8. **instagram_business_manage_insights** (аналитика Instagram)
9. **instagram_business_manage_comments** (комментарии)
10. **instagram_business_content_publish** (публикация)
11. **instagram_business_manage_messages** (DM)

### Советы для скринкаста:
- Записывать только экран браузера (без рабочий стол)
- Показать URL в адресной строке
- Не торопиться — каждое действие должно быть видимым
- Если данных нет (пусто) — сначала наполнить через "Обновить"
- Запись в 1080p, формат MP4 или MOV
