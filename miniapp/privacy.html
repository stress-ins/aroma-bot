Privacy Policy

Last updated: March 18, 2026

This Privacy Policy describes how TH_INS_AROMA ("Aroma Helper", "the App") handles information when you use our application.

1. Information We Collect

The App does not collect, store, or process personal data of end users. The App is used solely by its owner to:

  • Monitor publicly available trends in aromatherapy, olfactotherapy, and sound healing across social media platforms;
  • Publish content to the owner's own Instagram and Threads accounts via the official Meta APIs.

2. Use of Meta Platform APIs

The App connects to Instagram Graph API and Threads API to:

  • Read insights and analytics for the owner's business account;
  • Publish posts, carousels, and reels to the owner's accounts;
  • Search publicly available content by keywords for trend analysis.

The App accesses only the owner's own account data. No third-party user data is collected, stored, or shared.

3. Data Storage

All data processed by the App (trend analytics, generated content drafts) is stored on a private server controlled by the owner. No data is sold, shared with, or disclosed to third parties.

4. Cookies and Tracking

The App does not use cookies, web beacons, or any tracking technologies to track end users.

5. Third-Party Services

The App may use the following third-party services exclusively for content generation and trend analysis:

  • Meta Platform APIs (Instagram, Threads)
  • Telegram Bot API
  • AI services for content generation (Anthropic Claude, image generation APIs)

These services are used solely to process the owner's data and are governed by their own privacy policies.

6. Data Deletion

Since the App does not collect personal data from users, there is no user data to delete. If you believe the App has inadvertently collected your data, please contact us using the information below.

7. Children's Privacy

The App is not directed at children under 13 and does not knowingly collect data from children.

8. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated revision date.

9. Contact

If you have questions about this Privacy Policy, please contact us via Telegram: @aroma_trends_bot

Политика конфиденциальности

Последнее обновление: 18 марта 2026 г.

Настоящая Политика конфиденциальности описывает, как TH_INS_AROMA («Арома-помощник», «Приложение») обрабатывает информацию при использовании нашего приложения.

1. Какие данные мы собираем

Приложение не собирает, не хранит и не обрабатывает персональные данные конечных пользователей. Приложение используется исключительно его владельцем для:

  • Мониторинга публично доступных трендов в области ароматерапии, ольфактотерапии и звукового целительства в социальных сетях;
  • Публикации контента в собственных аккаунтах Instagram и Threads владельца через официальные API Meta.

2. Использование API платформы Meta

Приложение подключается к Instagram Graph API и Threads API для:

  • Чтения аналитики и статистики бизнес-аккаунта владельца;
  • Публикации постов, каруселей и reels в аккаунтах владельца;
  • Поиска публично доступного контента по ключевым словам для анализа трендов.

Приложение имеет доступ только к данным аккаунта владельца. Данные третьих лиц не собираются, не хранятся и не передаются.

3. Хранение данных

Все данные, обрабатываемые Приложением (аналитика трендов, черновики контента), хранятся на частном сервере, контролируемом владельцем. Данные не продаются, не передаются и не раскрываются третьим лицам.

4. Файлы cookie и отслеживание

Приложение не использует файлы cookie, веб-маяки или какие-либо технологии отслеживания для отслеживания конечных пользователей.

5. Сторонние сервисы

Приложение может использовать следующие сторонние сервисы исключительно для генерации контента и анализа трендов:

  • API платформы Meta (Instagram, Threads)
  • Telegram Bot API
  • AI-сервисы для генерации контента (Anthropic Claude, API генерации изображений)

Эти сервисы используются исключительно для обработки данных владельца и регулируются их собственными политиками конфиденциальности.

6. Удаление данных

Поскольку Приложение не собирает персональные данные пользователей, удалять нечего. Если вы считаете, что Приложение случайно собрало ваши данные, свяжитесь с нами, используя контактную информацию ниже.

7. Конфиденциальность детей

Приложение не предназначено для детей младше 13 лет и не собирает сознательно данные о детях.

8. Изменения в политике

Мы можем обновлять настоящую Политику конфиденциальности время от времени. Изменения будут опубликованы на этой странице с обновлённой датой редакции.

9. Контакт

Если у вас есть вопросы по данной Политике конфиденциальности, свяжитесь с нами через Telegram: @aroma_trends_bot
